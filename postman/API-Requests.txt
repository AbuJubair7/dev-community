- Controller: AuthController.register
- Auth: none
- Headers: Content-Type: application/json
- Body example:

  "email": "john@example.com",
  "password": "Passw0rd1"
}
- Response: 201 Created (user object)

2) POST /auth/login
- Controller: AuthController.login
- Auth: none
- Headers: Content-Type: application/json
- Body example:
{
  "email": "john@example.com",
  "password": "Passw0rd1"

- Response: 200 OK (authentication token / user info)

=== Users ===
Note: All `users` endpoints require `Authorization: Bearer <token>` (JwtGuard). Endpoints with SelfGuard additionally require the token user to match the `:id` path param.

1) GET /users
- Controller: UsersController.findAll
- Auth: JWT required
- Headers: Authorization, Accept: application/json
- Query params: optional pagination/filtering (not inferred statically)
- Response: 200 OK (array of users)

2) GET /users/:id
- Controller: UsersController.findOne
- Auth: JWT + SelfGuard
- Headers: Authorization
- Path params: id (string)
- Response: 200 OK (user)

3) PATCH /users/:id
- Controller: UsersController.update
- Auth: JWT + SelfGuard
- Headers: Authorization, Content-Type: application/json
- Body example (UpdateUserDto - partial):
{
  "fname": "John",
  "lname": "Smith",
  "password": "NewPass123"
}
- Response: 200 OK (updated user)

4) PATCH /users/:id/password
- Controller: UsersController.updatePassword
- Auth: JWT + SelfGuard
- Headers: Authorization, Content-Type: application/json
- Body example (UpdatePassDto):
{
  "oldPassword": "OldPass1",
  "newPassword": "NewPass123",
  "confirmPassword": "NewPass123"
}
- Response: 200 OK (success message)

5) DELETE /users/:id
- Controller: UsersController.remove
- Auth: JWT + SelfGuard
- Headers: Authorization
- Response: 200 OK (deletion result)
