API Requests

1. App API
-----------------------------------
Method: GET
URL: /
Controller/Function: AppController.getHello
Auth Required: None
Response Example: HTTP 200 (string)

2. Auth API
-----------------------------------
Method: POST
URL: /auth/register
Controller/Function: AuthController.register
Auth Required: None
Request Body (JSON):
{
  "fname": "John",
  "lname": "Doe",
  "email": "user@example.com",
  "password": "Password1"
}
Response Example: HTTP 201

Method: POST
URL: /auth/login
Controller/Function: AuthController.login
Auth Required: None
Request Body (JSON):
{
  "email": "user@example.com",
  "password": "Password1"
}
Response Example: HTTP 201

3. Users API
-----------------------------------
Method: GET
URL: /users
Controller/Function: UsersController.findAll
Headers: Authorization: Bearer <token>
Auth Required: JWT

Method: GET
URL: /users/:id
Controller/Function: UsersController.findOne
URL Parameters: id (string)
Headers: Authorization: Bearer <token>
Auth Required: JWT

Method: PATCH
URL: /users
Controller/Function: UsersController.update
Headers: Authorization: Bearer <token>
Auth Required: JWT
Request Body (JSON):
{
  "fname": "John",
  "lname": "Doe"
}

Method: PATCH
URL: /users/password
Controller/Function: UsersController.updatePassword
Headers: Authorization: Bearer <token>
Auth Required: JWT
Request Body (JSON):
{
  "oldPassword": "OldPassword1",
  "newPassword": "NewPassword1",
  "confirmPassword": "NewPassword1"
}

Method: DELETE
URL: /users
Controller/Function: UsersController.remove
Headers: Authorization: Bearer <token>
Auth Required: JWT
