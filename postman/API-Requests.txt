API Requests

1. App API
-----------------------------------
Method: GET
URL: /
Controller/Function: AppController.getHello
Auth Required: None
Response Example: HTTP 200 (string)

2. Auth API
-----------------------------------
Method: POST
URL: /auth/register
Controller/Function: AuthController.register
Auth Required: None
Request Body (JSON):
{
  "fname": "John",
  "lname": "Doe",
  "email": "user@example.com",
  "password": "Password1"
}
Response Example: HTTP 201

Method: POST
URL: /auth/login
Controller/Function: AuthController.login
Auth Required: None
Request Body (JSON):
{
  "email": "user@example.com",
  "password": "Password1"
}
Response Example: HTTP 201

3. Users API
-----------------------------------
Method: GET
URL: /users
Controller/Function: UsersController.findAll
Headers: Authorization: Bearer <token>
Auth Required: JWT

Method: GET
URL: /users/:id
Controller/Function: UsersController.findOne
URL Parameters: id (string)
Headers: Authorization: Bearer <token>
Auth Required: JWT

Method: PATCH
URL: /users
Controller/Function: UsersController.update
Headers: Authorization: Bearer <token>
Auth Required: JWT
Request Body (JSON):
{
  "fname": "John",
  "lname": "Doe"
}

Method: PATCH
URL: /users/password
Controller/Function: UsersController.updatePassword
Headers: Authorization: Bearer <token>
Auth Required: JWT
Request Body (JSON):
{
  "oldPassword": "OldPassword1",
  "newPassword": "NewPassword1",
  "confirmPassword": "NewPassword1"
}

Method: DELETE
URL: /users
Controller/Function: UsersController.remove
Headers: Authorization: Bearer <token>
Auth Required: JWT

7. Comments API
-----------------------------------
Method: POST
URL: /comments
Controller/Function: CommentsController.create
Headers: Authorization: Bearer <token>
Auth Required: JWT
Request Body (JSON):
{
  "postId": "6a0ea06ffa50fb2f7b57cbb9",
  "content": "This is a comment.",
  "parentId": "6a0ea06ffa50fb2f7b57cbba"
}

Method: GET
URL: /comments/post/:postId
Controller/Function: CommentsController.findAllByPost
URL Parameters: postId (string)
Query Parameters:
  - page (string, optional, e.g. "1")
  - limit (string, optional, e.g. "3")
  - replyLimit (string, optional, e.g. "5")
Headers: Authorization: Bearer <token>
Auth Required: JWT

Method: GET
URL: /comments/:id/replies
Controller/Function: CommentsController.findReplies
URL Parameters: id (string)

  - page (string, optional, e.g. "1")

Method: GET
URL: /comments/:id
Controller/Function: CommentsController.findOne

Headers: Authorization: Bearer <token>

Method: PATCH
